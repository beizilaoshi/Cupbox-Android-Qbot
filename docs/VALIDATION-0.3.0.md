- `scripts/build.ps1`：内置镜像校验、Release 构建、10 项 JVM 核心测试、Debug lint 与 Release vital lint 均通过。
- Android 12 x86_64 专用测试模拟器，1080×1920 / 420 dpi：常规套件报告 7 项、0 失败。其中 6 项实际执行，1 项大型网络验收按默认设置跳过。
- 实际执行项目：原生 PRoot 启动；内置 Ubuntu 在不可达网络 URL 下离线释放、SHA 校验与真实字节进度；Keystore 与记忆上限；OneBot → 模型 → 发送回执模拟链路；三主页面与四设置子页导航、深浅主题、保存栏、大肥鱼原版/自由演绎输入显隐；登录页与主页强制竖屏。
- 显式大型设备验收单独执行：首次完整安装取得真实 QQ 登录二维码，停止后无残余 QQ / Xvfb / PRoot 进程，复用环境重新启动再次取得二维码；1 项通过，234.244 秒（包括首次准备、清理与重启）。未预置 QQ、NapCat 下载缓存，Ubuntu 来自 APK。
- 签名 Release APK 新安装后，通过独立 adb/UI 脚本遍历首页、人格、设置及深浅主题。
- Release 完整首次初始化约 4 分钟取得真实二维码，并通过界面停止。复制/下载显示真实当前文件进度，安装阶段显示不定进度；已查看等待页截图与冷知识。最终签名包覆盖安装后保留环境、复用启动再次取得二维码，刷新二维码与通过界面停止均正常，停止后未发现 QQ / Xvfb / PRoot 进程。

这些耗时只是一台模拟器上的观察，不是性能基准，也不能推断骁龙 480 的表现。

# Cupbox Android 1.0.1

维护版本：修复聊天链路与界面稳定性问题，不改变安装方式、登录路线和已保存的配置。

- 版本：1.0.0 → 1.0.1
- versionCode：4 → 5（可覆盖安装 1.0.0）
- 安装包：Cupbox-Android-Qbot-1.0.1-release.apk

## 修复

1. **思考内容被当成正文**：推理模型只输出未闭合的 `<think>` 段，或把思考段放在正文之前时，旧版本会把思考内容清理失败并原样发到 QQ。现在会同时处理成对、未闭合、前置三种情况，清理后为空则跳过发送并记录原因。
2. **「已触发」统计偏高**：旧版本在去重、暂停、忙碌判断之前就自增计数，被丢弃的消息也计入。现在只有命中规则且未重复的消息才计数。
3. **主线程写数据库**：回复投递成功后的会话记忆写入从主线程移到工作线程，避免长时间使用后的卡顿。
4. **切换时重建界面**：人格选项、使用本机 QQ 开关原先在自身回调里同步重建界面，回调中的控件会被销毁。现在改为投递到主线程队列后再重建。
5. **残留状态**：重试本机环境时清除上一次的错误提示；二维码等待阶段不再沿用安装阶段的百分比；服务停止后进度回到初始状态。

## 优化

- 群号与关键词分隔符统一为「，,、;；空白」，此前只认逗号与换行。
- 群号列表与关键词新增长度上限（4000 / 2000 字）与明确提示。
- 记忆数据库开启 WAL；历史查询条数在数据层再夹一次 0–20。
- 运行记录弹窗新增「复制记录」。
- 模型失败日志附带截断后的原因（非中文内容仍统一显示为「网络或服务异常」，避免把服务商诊断信息带到界面）。

## 构建与测试

- CI 显式安装 `build-tools;35.0.0`，并增加 `concurrency` 取消、45 分钟超时、产物缺失即失败。
- 新增单元测试：未闭合 / 前置思考段、纯表情清理、分隔符解析、关键词长度上限。
- `UiSmokeTest` 的版本与构建号断言同步到 1.0.1 / 5。

## 升级说明

直接覆盖安装即可，已保存的模型配置、群规则、人格选择与登录资料都会保留；会话记忆数据库会自动切到 WAL，无需清理。
